# RA_Workshops
Workshops for technical stuff for my RAs (Memory and Brain Lab, Haigh Lab)

Workshop 1 runs in the browser (Google Colab), with nothing to install. Workshop 2 needs PsychoPy installed (instructions in its README and slides). Workshop 3 is a talk and discussion with interactive slides, with nothing to install. Workshop 5 runs in Colab like Workshop 1, with real (re-coded) data. Workshop 6 builds on Workshop 2 and needs PsychoPy.
