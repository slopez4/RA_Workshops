    Install PsychoPy

    PsychoPy needs to run on your own computer: it controls the screen and keyboard timing directly, so it can't run in a browser tab.

    1. Go to psychopy.org/download and download the Standalone installer for your computer. Use the same version as the lab computers (2026.1).
    2. Windows: run the .exe and accept the defaults.
      Mac: open the .dmg, drag PsychoPy into Applications. If macOS blocks it: System Settings → Privacy & Security → Open Anyway.
    3. Open PsychoPy. It starts in Builder; go to View → Coder (or Window → Coder).
    4. Mac only: System Settings → Privacy & Security → allow PsychoPy under Input Monitoring and Accessibility, or it won't see your keypresses.

    The download is large. Do it on good Wi-Fi before the session.

    The big picture

    Builder vs Coder

    Builder

    • Drag-and-drop routines and loops on a timeline
    • Fast to build standard experiments
    • Secretly writes a Python script for you

    Coder today

    • You write the Python yourself
    • See exactly what happens, and when
    • Makes Builder less mysterious and easier to debug

    Either way, an experiment is just a script that shows things, waits for responses, and writes a file.

    Sections 2–3 · Dialog and set up

    Who, and where to draw

    info = {"participant": "", "session": "1"}
dialog = gui.DlgFromDict(info, title="Animals & Plants")   # pop-up box fills in info
if not dialog.OK:
    core.quit()                                           # they clicked Cancel

win = visual.Window(size=(1000, 700), color="black", units="height", fullscr=False)

word = visual.TextStim(win, text="", height=0.1)   # create once, change .text later
kb = keyboard.Keyboard()
    • units="height": sizes are a fraction of screen height, so 0.1 = 10%. Looks the same on any monitor.
    • fullscr=False while developing; set True for real participants.
    The one concept to remember

    draw() → flip()

    .draw() paints onto a hidden canvas.
    win.flip() swaps it onto the screen, all at once, on the monitor's next refresh.

    fixation.draw()   # nothing visible yet
win.flip()        # NOW the + appears
core.wait(0.5)    # leave it up for 0.5 s
    • What would you see if you called draw() but forgot flip()?
    • Why is it useful that everything appears at the same moment?
    Answer

    Nothing: it stays on the hidden canvas. Showing everything on one flip means you know the exact moment a stimulus appeared, which is what reaction times are measured from.

    Section 4 · Instructions

    Write it once, use it twice

    def show_message(text):                 # def = define a function
    """Show a screen of text and wait for the space bar."""
    message.text = text
    message.draw()
    win.flip()
    kb.waitKeys(keyList=["space"])

show_message("Press A if it is an ANIMAL ... Press SPACE to start.")   # instructions
show_message("Done! Press SPACE to exit.")                               # the end screen

    A function bundles steps under one name. Instructions and the goodbye screen both use it, so a fix in one place fixes both.

    Fixed orders mix up the stimulus with when it appeared: practice, fatigue, or getting into an "animal" rhythm. Randomizing spreads those effects evenly. Because the order differs per person, we save the word on every row of the data.

    If you finish early

    Make it yours

    1. Easy: change the response keys to ← / → (key names: "left", "right"). Remember the instructions text!
    2. Easy: make the word yellow: color="yellow" in its TextStim.
    3. Medium: show each word twice: trials = STIMULI * 2 before shuffling.
    4. Medium: remove the feedback screen. When would you want no feedback?
    5. Harder: use pictures: visual.ImageStim(win, image="dog.png", size=0.4) and add an "image" field to each stimulus.
    6. Harder: add a break screen halfway through (hint: at the top of the loop, if trial_number == 5:).
